# Skills

Task workflows for `wheelos/hardware`:

- [Build and test](build-and-test/SKILL.md): Run structural validation, single-module dev tests, and isolated downstream SDK smoke tests.
- [Driver benchmark](driver-benchmark/SKILL.md): Profile driver CPU, zero-copy memory, I/O, and latency baselines, and generate sensor selection reports.
- [Module onboarding](module-onboarding/SKILL.md): Add a new hardware module or vendor driver following repository conventions.
- [BCR release](bcr-release/SKILL.md): Tag and publish independent `hardware.*` Bzlmod modules via `strip_prefix`.
- [Review](review/SKILL.md): Review module boundaries, dependency isolation, and build/runtime contracts.
